# DirectDraw2D_Game

**개발 기간** : 3주  
**팀 구성** : 2인팀

<br>

제 동생과 함께 진행한 2D 게임 프로젝트입니다.

동생은 타일맵 부분을 담당하였으며, 그 외 나머지 부분은 제가 구현하였습니다.

<br>

[Notion 협업 Tasks](https://shrub-syzygy-318.notion.site/19f325f2d2b280b6a45ec73c74edda11?v=19f325f2d2b280229681000c7a001518)


<br>

## 구현 목록

- **기본 시스템**
  - DebugManager
  - InputManager
  - SceneManager (비동기 Scene 전환) 
  - 카메라

<br>

- **게임 오브젝트**
  - 캐릭터 & 몬스터
  - Sprite 애니메이션

<br>

- **충돌 처리**
  - Raycast
  - AABB 충돌 검출
  - OBB 충돌 검출
  - Collision Layer
  - 충돌 반응
  - 간단한 2D 물리 (중력 및 충돌 시 밀어내기)

<br>

- **기타**
  - 기존 유영천님 Game 클래스 구조 리팩토링
  - 화면 크기에 따른 반응형 UI
